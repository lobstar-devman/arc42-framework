# Mermaid (UML / ERD)

> **Status:** stub — populated as UML or ERD diagrams are needed.

Used where the "official" standard is impractical: UML (class, sequence,
state diagrams — XMI interoperability is unreliable) and entity-relationship
diagrams (no dominant ERD standard exists). Written as plain Mermaid text,
diffs cleanly in git, and renders to SVG via the Mermaid CLI (`mmdc`) for
static embedding, or live in-page via the `mermaid2` MkDocs plugin.
