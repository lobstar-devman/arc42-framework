# Structurizr DSL (C4 Model)

> **Status:** stub — populated once `architecture/workspace.dsl` exists.

The system's structure — context, containers, components, and deployment
— is defined once in a single `workspace.dsl` file and rendered at every
C4 level by the Structurizr CLI. This is the single source of truth for
[Context & Scope](../arc42/03-context-and-scope.md),
[Building Block View](../arc42/05-building-block-view.md), and
[Deployment View](../arc42/07-deployment-view.md) — no C4 diagram is ever
drawn or edited by hand.
