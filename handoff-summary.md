# Handoff Summary — Architecting Toolkit Setup

**Date:** 2026-09-05
**Purpose:** Establish the standard toolkit, sources of truth, and documentation pipeline for architecting web applications as a living system. This is the toolkit to use for all future architecture steps.

---

## Decisions made

1. **Sources of truth use the real standard format wherever good open tooling exists**, falling back to a pragmatic text DSL only where the official standard is impractical, and to validated JSON only where nothing else fits:

   | Domain | Format |
   |---|---|
   | Business process | BPMN 2.0 XML |
   | Case management | CMMN 1.1 XML |
   | Decision logic | DMN XML |
   | System structure (C4 model) | Structurizr DSL |
   | API contracts | OpenAPI (YAML/JSON) |
   | UML (class/sequence/state) | Mermaid text |
   | ERD / database design | Mermaid `erDiagram` (or SQL DDL) |
   | Bespoke config/data | JSON + JSON Schema |

2. **Documentation framework: MkDocs Material**, structured per the **arc42** template, with system-structure diagrams following the **C4 model**. Chosen over Docusaurus/Jupyter/marimo as the de facto standard in the arc42/C4 community, lighter weight, and Python-native.

3. **Diagram tooling:**
   - [bpmn.io](https://bpmn.io) — BPMN/CMMN/DMN authoring and headless rendering
   - Structurizr CLI — C4 diagrams from Structurizr DSL
   - Mermaid CLI (`mmdc`) — UML/ERD rendering
   - Redoc / `@redocly/cli` — OpenAPI rendering and linting
   - `ajv-cli` — JSON Schema validation

4. **Core working principle:** nothing is ever hand-edited except the source-of-truth file itself. Diagrams and documentation pages are always regenerated by CI. The deliverable for every architecture step (e.g. database design) is **the source-of-truth file(s) + the linked generated documentation**, never a hand-drawn diagram or standalone prose doc.

5. **Environment:** Docker + Docker Compose, with the project directory **bind-mounted** into the container (not baked into the image), so edits to sources of truth are picked up live without a rebuild.
